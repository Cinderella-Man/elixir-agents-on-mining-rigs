When I draft a player, only the first keeper pick after the current position gets its drafted_at set; if there are several keeper picks in a row, the rest stay nil. Please make the draft update drafted_at on every consecutive keeper pick after the current pick and stop at the first pick that is not a keeper or has no player. For example, with the current pick at position 1 followed by keepers at 2 and 3 and a non-keeper at 4, picks 2 and 3 should both get a timestamp; pick 4 and any picks after it should stay untouched. The first update in the draft multi should still be keyed `:next_keeper_drafted_at_0`.
