When there are unfilled skipped picks but no team under the draft-time limit left to pick, DraftPick.available_with_skipped_picks?/2 currently returns false and DraftPick.picks_available_with_skips/1 returns nil. Those skipped picks should remain available instead: with picks [completed id 1, skipped id 2, completed id 3, skipped id 4], both id 2 and id 4 should be available and picks_available_with_skips/1 should return them in draft order, while completed id 3 is not available. If there are no unfilled picks, keep the existing false/nil result.
