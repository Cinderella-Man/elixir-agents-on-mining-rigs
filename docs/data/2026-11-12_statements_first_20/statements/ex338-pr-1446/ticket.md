I'm adding private fantasy leagues. Public leagues must behave exactly as they do today and stay visible to everyone, including people who are not logged in. A private league should only be visible to admins and to users who own at least one fantasy team in that league; anonymous users and logged-in users who do not own a team there must not see the league or be able to open its pages. Admin means the existing user `admin: true` flag. Owning a team means there is an existing owner record linking the user to a fantasy team in that league.

Add a persisted boolean `private?` field to fantasy leagues, defaulting to false and not nullable, so existing leagues remain public. It should be accepted by league changesets and available as a checkbox for the new private flag on the existing commissioner league form.

Add `Ex338.FantasyLeagues.can_access_league?/2`, taking a league and a user or nil, and returning a boolean. A public league is always accessible. A private league is accessible to an admin or to a user who owns a team in it. Nil and non-member users get false for a private league.

Add `Ex338.FantasyLeagues.filter_visible_leagues/2`, taking a list of leagues and a user or nil, and returning the visible leagues in their original order. Admins get the list unchanged. Everyone else gets all public leagues plus only private leagues where they own a team; nil behaves like a non-member. Update the existing league-by-status path so it accepts the current user while keeping the one-argument behavior working as before, and use that filtering for the primary leagues on the home page and for archived leagues.

The existing `LoadLeagues` plug should assign only visible leagues, using `conn.assigns.current_user` when present and treating a missing or nil current user as anonymous.

League pages must enforce the same rule, not just hide links. Any page tied to a league should send an unauthorized user to "/" with an error flash containing "You don't have access to that league." This covers the live league show page, live pages under a league id, controller pages under `/fantasy_leagues/:fantasy_league_id`, the live fantasy-team show page where the league must be derived from the team, and `/rules` when a `fantasy_league_id` query parameter is present. Public leagues, admins, and owners of a private league must still get through. For live pages the redirect/flash must use the normal live redirect error shape with destination "/" and flash key "error"; for controller pages use the normal redirect and flash behavior.

When leagues are listed on the home page, archived list, league navigation, or other league lists, keep the existing year and related ordering, but put private leagues ahead of public ones within the same year. Existing public-league behavior and anonymous access must not change.
