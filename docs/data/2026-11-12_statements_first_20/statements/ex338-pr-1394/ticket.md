Leagues need a commissioner-controlled draft-pick lock. Add a boolean `draft_picks_locked?` to leagues, defaulting to false and non-null so every existing league and every newly created league starts unlocked. It should be exposed in the league admin form as a boolean setting so a commissioner can turn the lock on and off.

When a league is locked, the draft-pick edit page and draft-pick update must both refuse to proceed. A GET to the edit page or a PATCH to submit a pick should redirect to that league's draft picks page at `/fantasy_leagues/<league_id>/draft_picks` and set the `:error` flash to exactly `Draft picks are locked for this league.`. The lock check should win even if the submitted params would be invalid. A blocked PATCH must not change the pick; for example, its `fantasy_player_id` must remain whatever it was. No draft submission, notification, reordering, or auto-draft side effect should happen for a blocked update. When the league is unlocked, edit and update behave exactly as they do now, including owner editing and validation errors.

On the draft picks page, when an available pick belongs to a locked league, show the text `Draft Locked` in place of the `Submit Pick` link. Do not render the edit link for that pick while locked, even for owners/admins; the locked message takes precedence over the owner/admin check. This should apply everywhere that link is currently shown. For unlocked leagues, keep the existing `Submit Pick` link and owner/admin visibility unchanged. Non-available picks should look the same as today.

Locking only blocks new pick edits/submissions and does not remove, hide, or alter existing submitted picks, queue order, or other league data. Unlocking restores the normal flow. Existing leagues default to unlocked, so this must not change any behavior unless `draft_picks_locked?` is true.
