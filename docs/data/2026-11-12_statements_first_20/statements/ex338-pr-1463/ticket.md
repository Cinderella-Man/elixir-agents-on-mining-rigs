Waiver validation still treats 20 active roster positions as the hard cap for add-only waivers. In a league that allows more roster spots, that incorrectly rejects the waiver and says a player must be dropped; a league with max_flex_spots set to 5 and a team already holding 20 roster positions should still be able to add a player without dropping one. It should use the league’s configured roster size plus the team’s flex adjustment when deciding whether the roster is full, instead of the fixed 20.
