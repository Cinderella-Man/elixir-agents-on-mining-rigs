Joining DeviceChannel is only checking that the topic starts with "device:", so a connected device can join `device:<some other id>` or `device:<its own id>:extensions` and then receive another device's firmware URLs, support scripts and local shell traffic. It should accept only the exact bare topic `device:<the connecting device's id>`; every other `device:*` topic, including other ids and `:extensions` variants, must fail the join as unauthorized and must not reach the platform/device join at all. The device's own bare topic has to keep joining normally and receiving updates. Use the channel's normal join-error map shape, with the error value `unauthorized`.
