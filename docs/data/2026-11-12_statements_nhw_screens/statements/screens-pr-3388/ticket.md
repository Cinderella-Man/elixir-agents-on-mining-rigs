On busway screens, when a normal section has a countdown departure and a headway row for the same route and headsign, they are being folded into one row, so one of the times disappears. For example, a Green-D Riverside departure 1 minute away plus `{route, 0, {7, 12}, "Riverside"}` should serialize as two Riverside rows in the original order: one with `%{type: :minutes, minutes: 1}` and one with `%{type: :headway, range: %{lo: 7, hi: 12}}`; reversing the input should reverse the times.

The same separation is needed in audio serialization on both busway and bus shelter screens. Consecutive-row grouping also needs to stop treating headways and first-trip/service-ended schedule rows as groupable with matching departures or with each other; only consecutive departure rows with the same route and headsign should still group together.
