Devices can report mem_used_mb without mem_used_percent — for example %{"mem_size_mb" => 7892, "mem_used_mb" => 100} — and the device details page and health tab blow up while rendering the percentage. The MB value should still be shown, and when mem_used_percent is missing the warning-colored "%" should simply be omitted; when it is present, keep showing the percentage as before.
