# Experiments registry

Every idea gets a row here as soon as it is written down, however small; that is what keeps work from being done twice.
Ideas the evidence argues against stay as rows marked **parked**, with the reason and what would reopen them. The
order of work is in [docs/plan.md](docs/plan.md).

**Now (2026-11-09):** the project starts. No model has run yet. A desk survey added rows E13–E45
([survey](docs/research/notes/idea_survey_2026-11.md), [study order](docs/research/notes/study_order_2026-11.md)); E14, a read of
the bench's published runs, is done. Rows E46–E53 are about collecting public training data
([guide](docs/research/notes/task_collection_guide.md)); E46, the project pool, is done. Rows E54–E61 are about self-improvement
loops ([report](docs/research/finetuning/reports/Recursive%20self-improvement%20for%20an%20Elixir%20model.md)).
